## Web Motion & Animation Libraries
- **[Remotion](https://remotion.dev/)** – React-based video and animation rendering engine. Perfect for programmatic motion design agents.
- **[Framer Motion](https://www.framer.com/motion/)** – Production-ready motion library for React.
- **[GSAP](https://greensock.com/gsap/)** – Industry standard for high-performance animations.
- **[Lottie](https://airbnb.io/lottie/)** – Lightweight animations from After Effects, renderable in web/native.
- **[Rive](https://rive.app/)** – Real-time interactive vector animations and state machines.
- **[Three.js](https://threejs.org/)** – 3D motion and WebGL for advanced agent-driven scenes.
- **[p5.js](https://p5js.org/)** – Creative coding for generative motion (see creative skill p5js).

## Video & Rendering Agents
- **ComfyUI** – Node-based visual AI workflows (load comfyui skill for image/video gen).
- **TouchDesigner** – Real-time visual programming (see touchdesigner-mcp skill).
- Custom agents for batch rendering, style transfer, motion capture.
