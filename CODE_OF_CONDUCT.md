# Code of conduct

This project follows the spirit of the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). In short:

- Be respectful and assume good intent, including toward first-time contributors and tool authors submitting their own work.
- Critique tools and pull requests, never people.
- No harassment, personal attacks, sexualized content, or publishing anyone's private information.
- Keep promotion honest: submit what you built, state what it needs to run, and do not inflate claims.

## Reporting

Report conduct problems privately to the maintainer through their GitHub profile ([frankxai](https://github.com/frankxai)). Reports are read in confidence. The maintainer may edit or remove comments, close pull requests, or block accounts that break these rules.
